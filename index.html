VoltageOS Flashing Guide

A complete step-by-step guide for installing and updating VoltageOS on Xiaomi Redmi Note 11 Pro 5G, Redmi Note 11 Pro+ 5G, Redmi Note 11E Pro and POCO X4 Pro 5G.

Device codenames: veux / peux

Important warning — read this first

Installing a custom ROM modifies important software on your phone. A mistake can cause data loss, boot loops or, in rare cases, a device that does not boot normally.

  • Your bootloader must already be unlocked.
  • Unlocking the bootloader normally erases all user data.
  • Make a complete backup before starting.
  • Use files made for veux/peux only.
  • Do not disconnect the USB cable while a flash is in progress.
  • Do not use random files, modified files or files from another device.
  • You are responsible for your device and your data.

Heads up

Your warranty is now void.

1

Before You Begin

Complete these checks before downloading or flashing anything.

Confirm your device

This guide is intended for the following devices:

  • Xiaomi Redmi Note 11 Pro 5G
  • Xiaomi Redmi Note 11 Pro+ 5G
  • Xiaomi Redmi Note 11E Pro
  • POCO X4 Pro 5G
Device codename:

The codename must be veux or peux. Do not continue if you are unsure which device you have.

You can usually check the model in Settings → About phone. The exact menu may be different depending on your current software.

Prepare your phone and computer

  • Charge the phone to at least 60%.
  • Use a reliable USB data cable.
  • Use a USB port directly on your computer.
  • Install Android platform-tools.
  • Install USB drivers if you are using Windows.
  • Keep the phone connected during each operation.
  • Close programs that may interfere with ADB or Fastboot.
  • Disable aggressive antivirus blocking if it prevents the tools from running.
Cable and port first:

Avoid USB hubs and damaged cables. Most “device not detected” problems are caused by the cable or USB port, not by the phone.

Back up your data

A clean installation formats the data partition and may erase internal storage. Back up everything important before continuing.

Photos and videos Copy them to a computer or cloud storage.
Documents Save downloads, recordings and work files.
Messages and contacts Confirm that synchronization or backup is enabled.
Authentication apps Export recovery codes before wiping the phone.
Do not rely only on files stored on the phone.

Do not keep your only backup on the phone. Formatting data can permanently remove files from internal storage.

Download and Prepare the Files

Organize everything before entering fastboot or recovery.

Files you may need

Download the files required for the installation method you want to use. The exact filenames and versions may change over time.

File Purpose Required?
initial-install.zip Contains the foundational boot images (boot.img, vendor_boot.img, dtbo.img) that are flashed individually in fastboot. New installation
boot.img Contains the boot and recovery environment for this device. Initial installation
vendor_boot.img Provides vendor boot components required by the ROM. Initial installation
dtbo.img Provides device-tree boot configuration. Initial installation
firmware.zip Provides low-level device firmware. Usually required
rom.zip The main VoltageOS operating system package. Required
gapps.zip Traditional Google applications. Optional
Filename note:

Names such as rom.zip, firmware.zip and gapps.zip are examples used in this guide. Your downloaded files will probably have longer version-specific names.

Download sources at a glance

What Where
Initial install package (recovery images) SourceForge — veux / recovery
VoltageOS ROM builds SourceForge — veux
Regional firmware Firmware channel
Sandboxed Google Play apps GrapheneOS Apps releases
Verify before you flash.

Always confirm that a package is built for veux or peux and matches your current Android version before using it.

Suggested folder layout

Create one folder on your computer and place the required files inside it. 

VoltageOS-veux/
├── platform-tools/
├── initial-install.zip
├── boot.img
├── vendor_boot.img
├── dtbo.img
├── firmware.zip
├── voltageos-rom.zip
└── gapps.zip

Keep original filenames unless a command specifically requires a rename.

How to unzip or extract files

  1. Open your Downloads folder.
  2. Right-click the downloaded archive.
  3. Select Extract All, Extract Here or the equivalent option.
  4. Open the extracted folder.
  5. Move the required .zip, .img or platform-tools files into your prepared VoltageOS folder.
Not every file should be extracted.

The initial install package is extracted, because the images inside it are flashed one by one. ROM, firmware and GApps ZIPs are not extracted — they are flashed as ZIPs.

Check for nested archives

A frequent mistake is selecting a ZIP that contains another ZIP. For example: 

Downloads/
└── VoltageOS-download.zip
    └── voltageos-rom.zip

Extract the outer archive first, then use the actual flashable ZIP inside. Do not flash a random folder or an incomplete archive.

Do not open and re-compress a ROM ZIP.

Re-compressing a flashable ZIP can change its structure and make recovery reject it.

3

Install and Test Platform-Tools

ADB and Fastboot allow your computer to communicate with the phone.

What are ADB and Fastboot?

ADB Android Debug Bridge is used when Android or recovery is running. It can send commands and perform an ADB sideload.
Fastboot Fastboot is used from the bootloader or fastbootd environment to write images to partitions and change boot modes.

Windows users

  1. Download and extract Android platform-tools.
  2. Open the extracted platform-tools folder.
  3. Click the address bar in File Explorer.
  4. Type cmd and press Enter.
  5. Use the commands in this guide from that window.
Note:

On Windows, you may need to type .\ before commands, for example .\adb devices or .\fastboot devices.

Linux and macOS users

  1. Download and extract platform-tools.
  2. Open a Terminal window.
  3. Change to the platform-tools directory.
  4. Run ADB and Fastboot commands from that directory.

Depending on your system, you may need to use ./adb and ./fastboot, or install them through your operating system package manager.

Test Fastboot before flashing

Boot the phone into bootloader fastboot mode first, then connect it to the computer and run: 

fastboot devices

A working connection normally displays a device identifier followed by the word fastboot.

Stop if nothing is displayed.

Solve the USB driver, cable or platform-tools problem before flashing.

Command cheat sheet

Every command used in this guide, and where each one is valid.

Command What it does Valid in
fastboot devices Lists phones connected in fastboot mode. Bootloader / fastbootd
fastboot flash <partition> <file>.img Writes an image to a partition. Bootloader fastboot
fastboot reboot Restarts the phone normally. Bootloader / fastbootd
fastboot reboot recovery Restarts directly into recovery. fastbootd only
adb devices Lists phones connected over ADB. Android / recovery
adb sideload <file>.zip Sends a flashable ZIP to recovery. Recovery (sideload mode)
adb reboot recovery Restarts into recovery. Android (USB debugging on)
Remember:

adb commands do not work in bootloader fastboot, and fastboot commands do not work inside Android or recovery.

4

Learn the Important Boot Modes

Knowing which mode you are using prevents many flashing mistakes.

Bootloader Fastboot

This is the mode normally entered with Volume Down + Power. It is used for flashing physical partitions such as boot, dtbo and vendor_boot.

Screen appearance:

You may see a Fastboot logo or the Xiaomi bunny logo.

Fastbootd

Fastbootd is a userspace fastboot environment. It is needed for dynamic (logical) partition operations, not for the image flashing steps used in this guide.

How to enter:

From recovery, choose the fastboot or reboot-to-fastboot option, or run fastboot reboot fastboot.

Recovery

Recovery is a separate maintenance environment used to factory reset the phone, install ZIP files and perform ADB sideloads.

Common button combination:

Hold Volume Up + Power while the phone is powered off.

Entering bootloader fastboot mode

  1. Power off the phone completely.
  2. Press and hold Volume Down + Power.
  3. Release the buttons when the Fastboot screen appears.
  4. Connect the phone to the computer.
  5. Run fastboot devices to confirm the connection.
Do not confuse the modes.

ADB commands usually do not work in bootloader fastboot, and fastboot commands do not work from the normal Android system.

5

Flash the Initial Install Package

Use this section when installing VoltageOS for the first time.

Download the initial install package

Download the latest initial installation ZIP from the official VoltageOS download location:

Open VoltageOS recovery downloads
Important:

The initial-install.zip file is not the complete ROM. It is only used to prepare the foundational boot components and recovery. Make sure the package is specifically for veux or peux.

Why the initial ZIP must not be flashed with fastboot update

The initial installation ZIP is not a complete system image package. It does not contain a normal system.img.

It contains the foundational images needed to start the custom recovery, such as:

  • boot.img
  • vendor_boot.img
  • dtbo.img
Do not use this command for the initial ZIP: 
fastboot --skip-reboot update initial-install.zip

This command expects a complete update package containing the required partitions, including a system image. Because the initial ZIP is not a complete ROM, it can fail with an error such as: 

could not load 'system.img'

Step 1 — Enter bootloader fastboot

  1. Power off the phone.
  2. Hold Volume Down + Power.
  3. Wait until the Fastboot screen appears.
  4. Connect the phone to your computer.

Confirm that your computer can see the phone: 

fastboot devices
Do not continue if no device appears.

Check the cable, USB port, drivers and platform-tools first.

Step 2 — Extract the initial install ZIP

The initial install package is not flashed as a ZIP. Extract it first, then flash every image inside it individually.

  1. Right-click the downloaded initial install ZIP.
  2. Choose Extract All / Extract Here.
  3. Open the extracted folder.
  4. Locate boot.img, vendor_boot.img and dtbo.img.
  5. Move those image files into your platform-tools folder so the commands below can find them. 
platform-tools/
├── adb
├── fastboot
├── boot.img
├── vendor_boot.img
└── dtbo.img
Check the files:

The three image files should be directly accessible from the folder where you will run the Fastboot commands.

Do not rename the images.

Keep the original filenames. If a file is renamed, the commands below will fail with “cannot load”.

Step 3 — Flash each image from the package

Stay in bootloader fastboot and flash the images one at a time. Wait for each command to report OKAY and Finished before running the next one.

1. Flash the boot image

fastboot flash boot boot.img

2. Flash the vendor_boot image

fastboot flash vendor_boot vendor_boot.img

3. Flash the dtbo image

fastboot flash dtbo dtbo.img
boot.img Provides the boot image and the recovery environment used by this device.
vendor_boot.img Provides vendor boot components required for the ROM to start correctly.
dtbo.img Provides device-tree configuration for the phone hardware.
Extra images If your package contains more images (for example recovery.img), flash them the same way: fastboot flash recovery recovery.img.
Do not interrupt a flash.

Keep the USB cable connected until every image has finished flashing. Disconnecting mid-write can leave the boot partitions incomplete.

Only flash the current slot.

Do not manually flash boot_a, boot_b, vendor_boot_a and vendor_boot_b. The ROM installation process handles the inactive slot as required.

Why flash images individually?

Flashing each image gives a clear success or failure message per partition, so you immediately know which step went wrong instead of reading a long combined log.

Got the MIUI screen instead of VoltageOS recovery?

If the phone boots into MIUI recovery after rebooting from this step, stop here and follow the dedicated fix: MIUI recovery appears after Step 3 → open the fix .

Step 4 — Immediately reboot directly to recovery

Without allowing the phone to boot into MIUI, run: 

fastboot reboot recovery

The phone should boot into the VoltageOS recovery environment. This is the safest way to prevent MIUI from replacing the custom recovery.

Do not choose normal system reboot.

If you let the phone boot normally into MIUI after flashing boot.img, Xiaomi's stock recovery protection may restore the MIUI recovery.

If fastboot reboot recovery is not accepted:

This command is only valid in fastbootd. Power off the phone and hold Volume Up + Power to enter recovery manually. The important part is not letting the phone boot into MIUI.

Step 5 — Format data in VoltageOS recovery

  1. In VoltageOS recovery, select Factory Reset.
  2. Select Format Data/Factory Reset.
  3. Confirm the format operation.
  4. Return to the main recovery menu.
This erases internal storage.

Make sure your backup is complete before confirming the format.

Step 6 — Sideload the main ROM ZIP

  1. Select Apply Update.
  2. Select Apply Update from ADB.
  3. Connect the phone to the computer if it is not already connected.
  4. Run the command using the main ROM ZIP.
adb sideload voltageos-rom.zip
Use the main ROM ZIP.

Do not sideload the file containing initial-install during this step. Use the normal ROM package, usually the one without initial-install in its filename.

Sideload progress may look unusual.

The terminal may appear to stop at a percentage below 100%. Wait until recovery and the terminal report that the operation is complete.

Step 7 — Reboot into VoltageOS

  1. Wait until the ROM installation has completely finished.
  2. Return to the recovery main menu if necessary.
  3. Select Reboot System Now.
  4. Wait patiently for the first boot.
First boot:

The first boot can take several minutes. Do not repeatedly force-restart the phone unless it has clearly been stuck for an unusually long time.

6

Flash Firmware

Firmware provides low-level device components required by the ROM.

Download the correct regional firmware

Download the latest firmware for your region from the available firmware source:

Open the firmware download source
Region matters.

Use firmware appropriate for your device and region. If you are unsure, ask in the device support group before flashing.

Method 1 — ADB Sideload

  1. In recovery, select Apply Update.
  2. Select Apply Update from ADB.
  3. Connect the phone to the computer.
  4. Run the command below using your actual filename.
adb sideload firmware.zip
Note:

The command must be run from the folder containing the firmware ZIP.

Method 2 — SD Card or USB OTG

  1. Copy the firmware ZIP to an SD card or USB drive.
  2. Connect it using an appropriate adapter if needed.
  3. In recovery, select Apply Update.
  4. Select Choose from sdcard or the available storage option.
  5. Select the firmware ZIP.
  6. Confirm the installation if prompted.
Tip:

SD card or OTG installation is useful when ADB drivers are not working correctly on your computer.

ADB sideload progress can look unusual.

It may appear to pause at a certain percentage or stop below 100%. Wait for the recovery and terminal to report completion before assuming that the installation failed.

7

Install the ROM

Choose one installation option according to your preferred Google app setup.

Clean flash warning:

A clean flash formats user data. Make sure your backup is complete before continuing.

Option 1 — Clean Flash: Vanilla

Choose this option if you want a ROM without Google applications installed.

  1. In recovery, select Apply Update → Apply Update from ADB.
  2. On the computer, run the command below using the actual ROM filename: 
adb sideload rom.zip
  1. Wait for the sideload to finish.
  2. If recovery asks whether to reboot to recovery, choose Yes.
  3. Select Factory Reset.
  4. Select Format Data/Factory Reset.
  5. Confirm the format operation.
  6. Select Reboot System Now.
First boot:

The first boot after a clean flash can take several minutes. Do not repeatedly force-restart the phone unless it has clearly been stuck for an unusually long time.

Option 2 — Clean Flash: Sandboxed Google Play

This option installs the ROM without traditional system-integrated GApps. Google components are installed as sandboxed applications after Android starts.

  1. Follow steps 1–8 from the Vanilla clean flash method.
  2. Boot into Android.
  3. Open the GrapheneOS App Store download page.
Download GrapheneOS Apps
  1. Install the App Store application.
  2. Open it after installation.
  3. Install Google Play services.
  4. Install Google Services Framework.
  5. Install Google Play Store.

Read more about Sandboxed Google Play on the official documentation:

Sandboxed Google Play documentation

For possible fixes and workarounds, check the community post:

VoltageOS community post
Why use sandboxed Google Play?

Google services run as regular applications instead of being deeply integrated into the system. This may provide a different privacy and permission model than traditional GApps.

Option 3 — Clean Flash: Normal GApps

Choose this option if you want to install a compatible traditional GApps package during the ROM installation process.

  1. In recovery, select Apply Update → Apply Update from ADB.
  2. Sideload the ROM ZIP:
adb sideload rom.zip
  1. Wait until the sideload has finished.
  2. Confirm Yes if recovery asks to reboot to recovery.
  3. Do not reboot to system.
  4. Return to Apply Update → Apply Update from ADB.
  5. Sideload your compatible GApps package:
adb sideload gapps.zip
  1. Wait for the GApps installation to finish.
  2. Select Advanced → Reboot to Recovery.
  3. After recovery restarts, select Factory Reset.
  4. Select Format Data/Factory Reset.
  5. Confirm the format.
  6. Select Reboot System Now.
Use compatible GApps only.

GApps packages must match the Android version and device architecture supported by your ROM.

8

Update an Existing Installation

Choose dirty flash or the built-in OTA updater.

Method 1 — Dirty Flash

A dirty flash updates the ROM while keeping your user data. Always keep a backup before updating.

  1. Boot into recovery.
  2. Select Apply Update → Apply Update from ADB.
  3. Sideload the new ROM:
adb sideload rom.zip
  1. Wait for the process to complete.
  2. Confirm recovery reboot if prompted.

If you previously installed normal GApps:

  1. Do not reboot to system.
  2. Choose Apply Update → Apply Update from ADB.
  3. Sideload the matching GApps package:
adb sideload gapps.zip
  1. Wait until it finishes.
  2. Select Reboot System Now.
Major Android upgrades may require a clean flash.

Follow the release instructions when moving between major versions, such as 4.x to 5.x.

Method 2 — OTA Updater

Important:

OTA updates may not work for major version upgrades. Check the release notes first.

  1. Open Settings.
  2. Open System.
  3. Open System update or Updater.
  4. Check for the latest build.
  5. Download the update.
  6. Tap Reboot when the updater asks.
  7. Allow the phone to complete the update automatically.
GApps note:

When using the built-in OTA updater, you normally do not need to manually flash GApps again. Follow the specific release instructions if they say otherwise.

9

Flash a Different Kernel

This step is optional and should only be used when required.

Important:

This procedure is not required after VoltageOS 5.6 unless the kernel maintainer or ROM instructions specifically tell you to use it.

  1. Download the required vendor_boot.img from the kernel download source.
  2. Reboot the phone into bootloader fastboot mode using Volume Down + Power.
  3. Connect the phone to the computer.
  4. Confirm that it is detected:
fastboot devices
  1. Flash the downloaded vendor boot image.
fastboot flash vendor_boot voltage-5.6-kernel-flash-vendor_boot.img
  1. Wait until the command completes successfully.
  2. Reboot to recovery using Volume Up + Power.
  3. Flash the desired kernel ZIP using ADB sideload or SD card/OTG.
  4. Select Reboot System Now.
Kernel compatibility is important.

A kernel made for another Android version, device or ROM can cause boot loops, crashes or loss of hardware functionality.

Troubleshooting and Frequently Asked Questions

Common problems and how to identify them quickly.

MIUI recovery appears after Step 3 instead of VoltageOS recovery

If the phone shows the MIUI recovery screen after Step 3, the custom boot image was overwritten. On veux/peux, the recovery lives inside the boot partition, so MIUI detects the modified boot image and restores the stock MIUI recovery as soon as it is allowed to boot.

Do not run fastboot update on the initial install ZIP.

The initial install ZIP is not a full ROM and does not contain system.img. Using fastboot update on it fails with could not load 'system.img'. It only contains the foundational images (boot, vendor_boot, dtbo) needed to bring up the custom recovery.

Follow these steps in this exact order:

  1. Boot into bootloader fastboot and flash the three images to the current active slot only: 
fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash dtbo dtbo.img
Do not manually flash the _a and _b slots.

Do not manually flash boot_a, boot_b, vendor_boot_a and vendor_boot_b. Flashing the current active slot is all that is required. The ROM installation process handles the inactive slot on its own.

  1. Immediately reboot to recovery. Do not let the phone boot into MIUI: 
fastboot reboot recovery
If that command is not accepted:

Power off and hold Volume Up + Power to enter recovery manually. The important part is not letting the phone boot into MIUI.

  1. In VoltageOS recovery, select Factory Reset → Format Data/Factory Reset and confirm.
  2. Go to Apply Update → Apply Update from ADB.
  3. Sideload the main ROM ZIP — the one without initial-install in its name: 
adb sideload voltageos-rom.zip
  1. Wait for the sideload to finish.
  2. Select Reboot System Now.
Why this works:

The initial install package only provides the foundational boot images. Entering recovery immediately prevents MIUI from overwriting them. Formatting data and sideloading the full ROM completes the installation.

The initial-install ZIP fails with “could not load system.img”

This happens when the initial-install ZIP is used with fastboot update.

The initial ZIP is not a complete ROM and does not contain system.img. Extract it and flash the three images manually: 

fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img
fastboot flash dtbo dtbo.img
fastboot reboot recovery
“adb” or “fastboot” is not recognized

The terminal is not currently inside the platform-tools folder, or platform-tools has not been installed correctly.

  • Open the terminal inside the platform-tools folder.
  • On Windows, try .\adb or .\fastboot.
  • Check that the executable files exist in the folder.
  • Install or update platform-tools if necessary.
fastboot devices shows nothing
  • Confirm the phone is actually in fastboot mode.
  • Try another USB port.
  • Try another data cable.
  • Install the correct USB drivers on Windows.
  • Restart the computer if the driver was just installed.
  • Run the command again from the platform-tools folder.
fastboot: error: cannot load 'boot.img'

Fastboot cannot find the image file you asked it to flash.

  • Make sure the initial install ZIP was extracted.
  • Make sure the .img files are inside the folder you opened the terminal in.
  • Check the exact filename with dir (Windows) or ls (Linux/macOS).
  • Do not rename the images unless an instruction tells you to.
  • If you are not in the correct folder, either move the images there or open a terminal in the folder that contains them.
ADB says “unauthorized”

This normally happens when Android is running and has not approved the computer for USB debugging.

  • Unlock the phone screen.
  • Accept the USB debugging authorization prompt.
  • Enable USB debugging in Developer options if needed.
  • Reconnect the cable and run adb devices again.

ADB sideload mode inside recovery is different from normal Android USB debugging and may not display the same authorization prompt.

The sideload percentage appears stuck

ADB sideload progress does not always behave like a normal progress bar. It may stop at a percentage while recovery continues processing.

Wait for both the terminal and recovery to report completion. Do not disconnect the phone just because the percentage is not moving.

Recovery says the ZIP is invalid
  • Make sure the download completed successfully.
  • Check that you selected the real flashable ZIP.
  • Check whether the file is nested inside another archive.
  • Confirm that the ZIP is made for veux/peux.
  • Download the file again if it may be corrupted.
  • Do not open and re-compress the ROM ZIP.
The phone boot loops after installation

A boot loop means the phone repeatedly restarts or never reaches Android.

  • Wait several minutes during the first boot.
  • Return to recovery using Volume Up + Power.
  • Check whether the ROM installation completed successfully.
  • Confirm that the firmware is compatible.
  • Check whether a required GApps package was installed correctly.
  • Perform the required factory reset if this was a clean installation.
  • Review the ROM release instructions before trying again.
Do not repeatedly flash random files.

If the problem continues, stop and ask for help with the exact device model, ROM version and error message.

I accidentally rebooted to the wrong mode

This is usually recoverable. Power the phone off and use the appropriate button combination:

  • Volume Down + Power: bootloader fastboot.
  • Volume Up + Power: recovery.

If Android starts normally, shut it down again before retrying the required button combination.

Can I disconnect the phone during a flash?

No. Keep the cable connected until the command and recovery both indicate that the operation is complete.

Disconnecting during a partition or system update can leave the installation incomplete.

Final Checklist

Use this checklist before considering the installation complete.

  • The phone is the correct veux/peux model.
  • The bootloader is unlocked.
  • Important data has been backed up.
  • The battery is sufficiently charged.
  • All images from the initial install package were flashed successfully.
  • The phone was rebooted directly to recovery — not into MIUI.
  • Data was formatted when required.
  • The correct firmware was installed.
  • The main ROM ZIP was sideloaded successfully.
  • The correct GApps option was used, if needed.
  • The phone boots successfully into VoltageOS / Android.
  • Basic hardware and network functions work.
  • A fresh backup has been created after setup.
Keep your files.

Keep the working ROM, firmware, extracted images and recovery files in a safe folder. They may be useful if you need to recover or reinstall the system later.
